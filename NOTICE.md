# Attribution and assets

The original Cataclysmic Crab Spawn mod is by ImMaxon and is licensed MIT according to its Modrinth project listing. The item texture in this port is byte-identical to the texture in the original 1.20.1 Forge JAR. The Java implementation and 1.21.1 data/model adaptations in this repository are the unofficial port.

The project logo is an AI-generated illustrative image created for this port. It is not an in-game screenshot and is not an asset from L_Ender's Cataclysm. It is included separately from the upstream MIT-licensed texture and code.
