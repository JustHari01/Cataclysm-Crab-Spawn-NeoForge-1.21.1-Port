# Cataclysmic Crab Spawn (UNOFFICIAL)

A NeoForge 1.21.1 port of [Cataclysmic Crab Spawn by ImMaxon](https://modrinth.com/mod/cataclysmic-crab-spawn), originally released for Forge 1.20.1. The original project lists the MIT license.

## What it adds

The craftable **Suspicious Looking Crab** item summons the Amethyst Crab from L_Ender's Cataclysm. The item retains its original crafting recipe and texture, dark-gray tooltip, beacon selection sound, item-use activation, uncommon rarity, one-item stack size, and Tools & Utilities creative-tab entry.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.267 or newer
- L_Ender's Cataclysm for NeoForge 1.21.1
- Java 21

## Build

Run `gradlew build` on a Java 21 installation. The build produces the mod JAR and source JAR under `build/libs`.
